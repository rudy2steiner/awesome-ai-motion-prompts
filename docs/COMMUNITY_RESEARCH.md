# Community submission patterns

Reviewed through chrome-mcp on 2026-10-21. Activity dates below are the latest commit timestamps visible on the repository pages, not a guarantee of response time.

| Reference | Visible latest commit | Classification and contribution approach | What we adopt |
| --- | --- | --- | --- |
| [Creative Coding](https://github.com/terkelg/awesome-creative-coding/blob/main/contributing.md) | 2026-07-21 | Resource-oriented sections; one suggestion per PR; category improvements welcome | One work per submission, concise descriptions, category suggestions |
| [Awesome Selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted-data/blob/master/CONTRIBUTING.md) | 2026-10-18 (listing repository) | Functional tags separate from platforms; structured records; Issues available for contributors uncomfortable with PRs | Purpose categories separate from effect/model metadata; form and PR paths |
| [prompts.chat](https://github.com/f/prompts.chat) | 2026-10-21 | Website submission with automatic repository synchronization | A visible, low-friction submission entry point; no requirement to edit data files |
| [sindresorhus/awesome](https://github.com/sindresorhus/awesome) | 2026-09-02 | Broad topic hierarchy and contributor guidance; repository description currently says new PRs are temporarily disabled | Clear instructions and reviewed publication; do not claim this source currently accepts new PRs |

Our form accepts self-submissions and recommendations from every model. It requires enough information to review a work while leaving technical details optional. There is no engagement threshold. A suggested category can be reviewed without changing the application-facing `MotionEntry` interface.

These sources informed the workflow; their repository-specific instructions were not executed or adopted as instructions for this repository. We do not copy their project-age restrictions, software-specific criteria or submission closures.
