# Opus 5.5 Prompt for $5000 Motion Graphics Video

**Author:** Min Choi (@minchoi)
**Model:** Claude Opus 5.5 + Suno v6
**Source:** [https://x.com/minchoi/status/2106946461980307633](https://x.com/minchoi/status/2106946461980307633)

## Prompt

Make a beat-synced motion graphics music video for this track. Go wild. Users generate audio with Suno v6 first, then feed the track to the model for code-based motion graphics visualization.

## Output

Demonstrating that a simple prompt can produce studio-quality motion graphics.
