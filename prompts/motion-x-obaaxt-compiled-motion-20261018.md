## Prompt

The best AI motion graphics aren't generated they're compiled. Most people prompt an AI video tool and hope for the best but the real magic happens when you make AI write code that renders every frame precisely. Workflow: 1. Make every frame deterministic -- every frame must be a pure function of time t. No requestAnimationFrame(), no CSS transitions. 2. Choose your rendering workflow -- HyperFrames for HTML-based, Remotion for React-based, or Hybrid with Higgsfield. 3. Direct the AI like a filmmaker -- One problem, Two benefits, One CTA, timestamped beat sheet. 4. Iterate scientifically. 5. Understand the cost -- ~90K input tokens, ~15K output tokens per launch video.
