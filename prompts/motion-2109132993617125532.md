## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
请用 Three.js 写一个单文件 HTML（index.html），做一个"徒步纪实风格"的 3D 场景，用来录屏做解说视频。

【基本要求】
- Three.js 通过 CDN（cdnjs 或 jsdelivr）引入，不需要构建工具，浏览器双击即可运行。
- 画面严格 16:9，内部按 1920×1080 设计，窗口缩放时等比居中，黑边填充。
- 所有可调参数（地形种子、路线点、相机速度等）集中放在文件顶部的 CONFIG 对象里。

【地形】
- 用多层噪声（Simplex/Perlin，自己实现即可）生成一条南北走向的高山峡谷：两侧高山、中间谷底，谷底有一条蜿蜒的河道。
- 按高度和坡度上色：山脊深褐/灰、坡面土黄、谷底浅黄、河道蓝灰，山顶可有少量积雪。
- 加雾和平行光，营造高原干燥冷色调氛围。

【路线与人物】
- CONFIG 里用一组 (x, z) 路径点定义徒步路线，用 CatmullRomCurve3 生成平滑曲线并贴合地形高度。
- 路线渲染为醒目的红色粗线（带轻微发光），已走过部分亮红色，未走部分半透明。
- 一个红色低模小人（胶囊体+球头+红色外套即可）沿路线匀速行走，可设置速度，支持暂停。
- 支持在路线上放"事件标记点"（如集合点、失踪点），显示为带文字的立式标牌或脉冲圆圈。

【相机】
- 四种模式，数字键 1-4 切换，切换时平滑过渡：
  1. 高空俯瞰（沿路线前方飞行，微微倾斜）
  2. 跟随（人物斜后上方）
  3. 环绕（绕着人物缓慢旋转）
  4. 自由（鼠标拖动旋转，滚轮缩放，WASD 移动）
- 相机速度、高度、俯仰角可在 CONFIG 里调。

【界面叠加层（HTML/CSS）】
- 左右两侧各一列人物卡片：方形头像框（先用纯色+首字占位，可通过 CONFIG 换成图片 URL）、名字、身份小字。
- 人物状态：正常 / 遇难（卡片变灰并加红色边框）/ 失踪（卡片半透明并显示问号）。
- 底部居中大字幕区，白字黑描边，支持高亮关键词（用 [[关键词]] 标记，显示为黄色）。
- 右上角显示"第 X 集"标题和当前进度条（可选）。

【时间线驱动】
- 在 CONFIG 里用一个数组 TIMELINE 描述剧情，每项含 time（秒）和 action，例如：
  { time: 0,  action: "camera", mode: 1 }
  { time: 3,  action: "subtitle", text: "那你为什么还敢[[参加]]？", duration: 4 }
  { time: 8,  action: "walk", from: 0, to: 0.4 }       // 人物在路线上的进度 0~1
  { time: 15, action: "status", member: "胡杨林", state: "missing" }
  { time: 20, action: "marker", at: 0.6, text: "失踪点" }
- 播放逻辑：按 Space 开始/暂停，R 重置，时间到了自动触发对应事件。
- 页面左上角显示一个小的调试面板（当前时间、相机模式），按 H 一键隐藏所有调试和提示，录屏时保持画面干净。

【示例内容】
- 预置 8 位虚构队员（铁镐-组织者、千鸟、胡杨林、咪咪、队员5～8），一条约 90 秒的演示时间线，覆盖：开场俯瞰、行进、事件标记、人物状态变化、结尾字幕。

【代码要求】
- 代码清晰分区并加中文注释（地形、路线、人物、相机、UI、时间线）。
- 保证在普通笔记本上能稳定 30fps 以上，地形分辨率不要过高（约 256×256 顶点）。
- 完成后告诉我：如何修改路线、如何换头像、如何新增时间线事件。
```
