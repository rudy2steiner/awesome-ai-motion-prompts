# Interactive Floor Plan That Builds on Scroll

## Prompt

```
How I built a floor plan that builds into a 3D house on scroll. Using Opus 5.5 as the starter prompt, I created a single HTML file with Three.js that shows a 2D floor plan at the top of the page. As the user scrolls down, the walls extrude upward, the roof assembles itself, and furniture appears in each room. The camera orbits slowly around the model as you continue scrolling. The whole experience is driven by scroll position mapped to animation progress. GitHub-hosted demo with full source code and prompts included.
```
