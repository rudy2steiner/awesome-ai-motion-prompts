# 99 Cinematic Styles in One Free Claude Code Plugin

**Author:** Eugenio Fierro (@EugenioFierro3)
**Model:** Claude Code (community plugin)
**Source:** [https://x.com/EugenioFierro3/status/2121361742404161954](https://x.com/EugenioFierro3/status/2121361742404161954)

## Prompt

99 visual styles organized into 15 categories for animation, including 1930s Rubber Hose cartoons and Swiss motion graphics. Each style comes with ready-to-use instructions. Select a preferred style and apply the bundled guidance rather than writing custom prompts.

## Output

Comprehensive style library plugin for Claude Code covering 99 cinematic animation styles.
