# Blender and Godot Scripted from TypeScript: Raea Workflow

**Author:** Shane (@shinyobjectz_)
**Model:** Blender + Godot (GodotJS) + Raea + Three.js + React Three Fiber + Bevy
**Source:** [https://x.com/shinyobjectz_/status/2120806459495883002](https://x.com/shinyobjectz_/status/2120806459495883002)

## Prompt

Blender and Godot, scripted from TypeScript. raea/blender types the whole Python API. raea/godot types every godotengine class and runs on GodotJS. Either engine is one more step in a raea workflow: raeca blender run, raeca godot run. Each half of the video was drawn by its own engine, from one shared timeline.

## Output

Unified TypeScript workflow scripting both Blender and Godot engines.
