# How to Become a Motion Designer with Opus 5.5: 12-Step Guide

**Author:** kocer (@kocer_eth)  
**Model/Tool:** Claude Opus 5.5 + Claude Code  
**Posted:** 2026-10-07  
**Source:** [https://x.com/kocer_eth/status/2107903802514768027](https://x.com/kocer_eth/status/2107903802514768027)

## Prompt

12-step workflow: 1.Setup (check dependencies, reproducible test scene) 2.Typography (8-second study, clear timing) 3.References (analyze visual references) 4.UI States (animate component through states) 5.Product Animation (real screenshots, one interaction) 6.Illustration (static to animated explainer) 7.Depth Study (3D + lighting, Three.js) 8.Charts (data comparisons, fixed axes) 9.Logo Loops (seamless, no generic spinning) 10.Sound Sync (shared timeline) 11.Revision (fix specific timestamps) 12.Export (16:9, 1:1, 9:16).
