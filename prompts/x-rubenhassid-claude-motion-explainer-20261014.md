# Claude /motion Prompt Template for Explainer Videos

**Author:** Ruben Hassid (@rubenhassid)
**Model:** Claude Motion + Opus 5.5
**Source:** [https://x.com/rubenhassid/status/2110324757615042751](https://x.com/rubenhassid/status/2110324757615042751)

## Prompt

/motion Turn [THIS REPORT / THESE NOTES / THIS CHART] into a [20]-second explainer. Who will watch it: [YOUR AUDIENCE]. Where it will play: [ALL-HANDS SCREEN / LINKEDIN / A SALES CALL]. The one thing they must remember: [ONE SENTENCE]. Use my [LOGO / SCREENSHOTS / BRAND COLORS], attached. One idea per scene. Few words on screen. End on: [YOUR LAST LINE].

## Output

Reusable template for turning reports and data into short explainer videos.
