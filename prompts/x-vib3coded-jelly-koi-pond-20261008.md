# Interactive 3D Jelly Koi Pond with Soft-Body Physics

**Author:** Vib3Coded (@vib3coded)
**Model:** Three.js (WebGL 2)
**Source:** [https://x.com/vib3coded/status/2108256735886487863](https://x.com/vib3coded/status/2108256735886487863)

## Prompt

Build an interactive 3D Jelly Koi Pond in a single self-contained HTML file. Features a translucent oval pond with koi fish and lily pads. Users can click and drag any part of the pond to stretch and lift it, triggering local deformation and wobble effects. Requires procedural geometry and minimal editorial layout with specific controls.

## Output

Interactive soft-body physics simulation with user-deformable jelly pond.
