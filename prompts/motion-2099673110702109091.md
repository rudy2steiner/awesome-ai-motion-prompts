## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
1. I write a short prompt file for the scene the setting, what has to happen, one fixed style sentence every asset must end with, any previously generated models to reuse (sometimes I love the model style but the overal scene is meh), the scene rules, and the print post process. At this point we don't lists the assets.

2. Model Stage A - DeepSeek designs the asset list. It gets the brief and returns JSON only a scene name and 6 to 13 assets (configurable), each with a name, role, instance count, and an image prompt in its own words. This is super quick takes maybe 10-20 seconds.

3. The asset service builds the assets. For each entry, a runner posts DeepSeeks image prompt to a service running on my 5090 rig. It appends the framing rules (single object, plain background, three-quarter view), generates a concept image with Krea2 on ComfyUI, sends that to TRELLIS.2, and drops the textured GLB into the gallery's assets folder. This takes around a minute per asset.

4. Analysis. A Python script measures every GLB: forward axis, bow and stern, top, any action points, plus a rotation that puts forward on +Z. All of it goes into the asset manifest.

5. Model Stage B - DeepSeek writes the page in a single turn. I give it the original brief, the asset manifest (paths, sizes, counts), each assets concept image so it can see what it's placing (I skip this for non vision models), and the standing page rules (three.js with the GLTF loader, terrain or starfield built in code, lighting, camera, particles, loading overlay, the post shader). This is what generates the single page.

The last part is obviously my QA and determining if I should start from scratch or prompt a fix or 2.
```
