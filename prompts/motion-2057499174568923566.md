## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
Provide a single self-contained HTML file using only HTML, CSS, JavaScript, Three.js from a CDN, and one GLSL fragment shader.

Create a full-screen animated shader that looks like flying forward through an endless glowing tunnel. Keep the implementation simple: render one full-screen plane with a fragment shader. Do not use raymarching, 3D geometry, physics, particles, or complex scene objects.

In the fragment shader, convert the pixel coordinates to polar coordinates using angle and distance from the center of the screen. Use the angle to create repeating radial bands around the tunnel, and use distance plus time to make the bands scroll toward the viewer. Add layered sine waves and simple fractal-style repetition so the tunnel wall appears detailed, but keep it stable and readable. The center should look like a dark vanishing point, while the outer area shows glowing tunnel walls moving outward.

Use deep blue, violet, magenta, and cyan colors with bright highlights. Add a soft vignette, slight glow, and smooth animation. The result should feel like an endless neon fractal tunnel screensaver, but the code should stay simple and robust. There should be no text, no UI, and no controls. It should run automatically forever.
```
