# Tin Knight: After Dark - Fable 5.2 Drawing-to-Survival Game

**Author:** Higgsfield AI (@higgsfield_ai)
**Model:** Fable 5.2 + GPT Image 2.6 + Meshy 7 + Nano Banana 2.1 + Mirelo + ElevenLabs + Higgsfield MCP
**Source:** [https://x.com/higgsfield_ai/status/2120003817584361926](https://x.com/higgsfield_ai/status/2120003817584361926)

## Prompt

Fable 5.2 turned one drawing into a toy shop you have to survive. Workflow: 1) GPT Image 2.6 for concept art with specific palette and ink work. 2) Character design with exhaustive text descriptors (silhouette, materials, hex codes, fixed imperfection). 3) Meshy 7 for rigged 3D models. 4) Nano Banana 2.1 for tileable textures. 5) Mirelo for sounds, ElevenLabs for voices.

## Output

End-to-end character animation pipeline from drawing to playable game/animation.
