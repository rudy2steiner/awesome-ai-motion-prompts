# Three-Live: Converting AI-Generated Three.js to WebXR Formats

**Author:** Google Open Source (@GoogleOSS)
**Model:** Three-Live (Apache 2.0, Rust/Boa compiler) + Three.js + glTF + USDZ + WebXR
**Source:** [https://x.com/GoogleOSS/status/2117704406174941360](https://x.com/GoogleOSS/status/2117704406174941360)

## Prompt

Three-Live is an Apache 2.0 library and on-device Rust/Boa compiler that converts procedural Three.js scripts into GLB, USDZ, and WebXR formats in milliseconds. Enables AI-generated 3D web content to be used in immersive AR/VR applications.

## Output

Google open-source library for converting Three.js scenes to immersive WebXR formats.
