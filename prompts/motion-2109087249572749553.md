## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
Make a fully interactive music video for this song as a single HTML file, at the level of a motion designer, sound engineer and creative director's showreel. The first frame has to stop the scroll and hook the viewer. Go all out.

Lyrics are below. Sync them word by word to the actual vocal. Separate the stems first, then time every word from the vocal track rather than estimating. Detect tempo, beats, kicks and snares, and drive the visuals from them.

Rules:
- One visual and type system across every section. Quiet sections should feel like the same video with the energy held back, not a different style.
- Every word must be crisp and readable over the effects. Glow and trails go behind the type, never through it.
- Give each lyric its own visual idea where it fits. No section should be filler.
- Don't add any audio to the song unless I ask.
- Interactions: hold to muffle the band, tap for a spark quantized to the beat, scroll for gain, stem mute buttons, a scrubbable timeline.
- Include an "Export 1080p video" button that renders every frame on a fixed clock and saves a 1920x1080 16:9 MP4 (H.264 + AAC) with the audio muxed in.
- Make the HTML file run on its own by double-clicking it in Chrome, with the audio built in.

[LYRICS WITH SECTION TAGS]
```
