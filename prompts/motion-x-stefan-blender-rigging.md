## Prompt

```
Two Anthropic engineers built a prompt system that creates rigged Blender creatures from skeleton first. The FRAME system: specify limb count, joint positions, and weight distribution before any mesh is generated. Anatomy before appearance. The skeleton defines the movement, the mesh defines the look. Start with the bones, add muscles, then skin. The prompt asks Claude to first generate a complete skeletal rig with inverse kinematics, then wrap it in a creature mesh that deforms naturally with the skeleton. Output: a Blender file with a fully rigged, animated creature ready for rendering.
```
