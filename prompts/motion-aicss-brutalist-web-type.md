## Prompt

```
Make a 10-second brutalist web-type piece: a raw HTML page that builds itself in hard cuts.

<inputs>
Studio: STATIC ROOM. Statements: "NO EASING." / "NO SHADOWS." / "JUST HTML." Headline: "WEBSITES" / "THAT LOAD."
</inputs>

<direction>
Palette: white #FFFFFF, black #000000, link blue #0000EE, visited purple #551A8B, highlight yellow #FFFF00.
Type: browser defaults only. font-family: serif for body; font-family: monospace for statements at 200-240px.
Grid: one 2px black border system, 120px left margin, everything flush left.
Motion is hard cuts. Every change happens on a single frame: no tweens, fades, slides or transitions.
Banned: easing of any kind, opacity fades, transitions, rounded corners, shadows, gradients, web fonts.
</direction>

<build>
One self-contained index.html, 1920x1080 stage, 60fps. No web fonts: the browser's own serif and monospace are the point.
</build>
```
