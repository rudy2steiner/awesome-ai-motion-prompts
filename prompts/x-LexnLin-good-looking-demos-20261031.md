# How to Prompt AI to Build Good Looking Demos

**Author:** Leon Lin (@LexnLin)
**Model:** Opus 5.5 + GPT Image Gen + Three.js + Claude Code
**Source:** [https://x.com/LexnLin/status/2116662591363690999](https://x.com/LexnLin/status/2116662591363690999)

## Prompt

Build me a massive, ultra-detailed 3D world in three.js based on the 9 reference images I attached. Zero external assets. Match the references as closely as possible. Iterate for as long as it takes. Aim for 99.9% similarity. References carry most of the quality. Generate target images first, then instruct the model to clone them in code.

## Output

Methodology for high-fidelity demo creation using reference-first prompting.
