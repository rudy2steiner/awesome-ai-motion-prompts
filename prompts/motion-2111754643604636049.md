## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
build a single html file (three.js) that renders a 3x3 puzzle cube in a 1080x1080 square and solves it on camera with a timer.

1. standard colors: white up, yellow down, green front, blue back, red right, orange left. no whole-cube rotations.
2. apply this scramble in wca notation: D2 R' F U2 B' L2 D' R2 U F2 L' B2 U' R D2 F' L U2 B R'
3. solve it your own way - any method, any number of moves. replaying the scramble backwards is not allowed.
4. every move animates in exactly 0.35s with a 0.05s pause.
5. show a timer that stops the moment the cube is solved, plus the current move and a move counter.
6. the cube must actually end fully solved.
```
