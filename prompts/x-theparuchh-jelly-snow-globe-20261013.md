# Interactive Jelly Snow Globe with Custom Physics

**Author:** Paruchh (@theparuchh)
**Model:** Three.js (Procedural Physics)
**Source:** [https://x.com/theparuchh/status/2110046350142235020](https://x.com/theparuchh/status/2110046350142235020)

## Prompt

A JELLY SNOW GLOBE IN THREE.JS - one HTML file with procedural physics, no external libraries. Clear glass that bends the view like a real lens, approximately 6000 floating snowflakes inside the globe. Interactive features: shake the globe, switch to night mode, step inside the village, or drop it to shatter the glass. Jelly houses exhibit delayed wobbling when shaken.

## Output

Interactive snow globe with jelly physics and multiple user interaction modes.
