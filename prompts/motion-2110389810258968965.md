## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
Make a one-minute video about the Claude mascot, Clawd. You can find assets online, like SVGs, then recreate and animate them yourself. Be as creative as you possibly can. Render 3D objects: Claude Code terminals, nature, whatever fits, and make it as good as you can. I don't want any text, just animation, and I mean a real video, not just motion graphics.

Think of crazy ideas I would never come up with, and make every scene look phenomenal: clean and detailed. I want people to watch it and think "yo, this is crazy, how did AI make this?" You can take inspiration from things online, but don't copy anything. Invent your own stuff.

For the sound, no sounds made in code. Only use free, professional sounds and assets from online. Make it satisfying and high quality.

don't create slop, I want to see art and creativity. No fonts, no text, only clean animations of Clawd.
```
