# Interactive Soft-Body Octopus in Clear Jelly with XPBD Physics

**Author:** Vib3Coded (@vib3coded)
**Model:** Three.js (WebGL 2) + XPBD Physics + Claude Opus 5.5
**Source:** [https://x.com/vib3coded/status/2121757817883271496](https://x.com/vib3coded/status/2121757817883271496)

## Prompt

Build a single-file interactive three.js (WebGL 2) page featuring a soft-body octopus cast in clear jelly. Generate creature from signed distance field, simulate using XPBD on fixed 60 Hz step. Users interact via grabbing or feeding gummy crabs. Glossy golden eyes with dark bar-shaped pupils and trapped bubbles. Khronos PBR Neutral tone mapping. Audio via Web Audio API.

## Output

Advanced soft-body physics simulation with user interaction in browser.
