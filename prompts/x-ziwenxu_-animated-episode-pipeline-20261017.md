## Prompt

Make a 20 to 30 minute animated episode. Act as the director. Create original storylines using external assets like SVGs or Blender MCP tools. Avoid on-screen text except credits. Use only professional audio sources. Workflow demands iterative rendering with self-review notes to ensure high-quality output without slop.

## Output

Ambitious long-form animated episode generation with quality gates.
