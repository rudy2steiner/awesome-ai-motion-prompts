# Motion to Code: Text/Image/Video to Editable Animation Code on fal

**Author:** fal (@fal)
**Model:** Motion to Code API (GSAP + GLSL output)
**Source:** [https://x.com/fal/status/2115599892471021865](https://x.com/fal/status/2115599892471021865)

## Prompt

Describe an animation, or drop in an image or a video, and receive back editable code: a GSAP page animation or a looping GLSL shader. Natural language to production-ready animation code.

## Output

fal.ai tool converting text/image/video descriptions to editable GSAP or GLSL code.
