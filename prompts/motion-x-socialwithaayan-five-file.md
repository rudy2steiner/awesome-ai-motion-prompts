## Prompt

```
Five-File Studio methodology for product launch videos. Architecture: CLAUDE.md (project brief), LOOK.md (visual direction), kit/ (assets folder), scenes/ (individual scene prompts), timeline (beat-synced rendering). Five clip prompts: 1) Hook - bold kinetic type opening, 2) Demo - product screenshots sliding in, 3) Morph - shape transitions between features, 4) Proof - data visualization and testimonials, 5) End Card - logo and call to action. Video-as-code with seek(t) function for deterministic frame rendering via Playwright, FFmpeg compositing. Cost: approximately $27 in API calls vs $5,000 studio alternative. Real assets only: SVG logos, product fonts, actual screenshots.
```
