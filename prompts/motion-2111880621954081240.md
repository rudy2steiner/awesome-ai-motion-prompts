## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
Build a single HTML file with Three.js. It opens on an AutoCAD-style dark screen with a command line at the bottom, where real commands type out (LINE, OFFSET, COPY, INSERT, DIMLINEAR) while a crosshair cursor clicks and snaps on the drawing. Draft a 92 m² apartment in the order a drafter would: grid lines, a 400×400 mm column copied to every crossing, 300 mm block walls with 150 mm insulation, doors and windows, furniture at real sizes, dimensions, room areas and a 1:50 sheet. Then a selection window grabs the plan and the CAD screen turns into a 3D scene that builds the apartment step by step from the same drawing: concrete columns, block walls, insulation, lintels, windows and swinging doors, oak and tile floors, kitchen and bath, then every piece of furniture dropping into the spot where it was drawn, while the camera flies around it. Everything runs on one timeline, with a button that renders it frame by frame to a 1440p60 MP4 (WebCodecs + mp4-muxer) so the video never lags.
```
