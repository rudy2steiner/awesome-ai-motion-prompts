# UniMate: Open-Source Text-to-Animation for 3D Characters

**Author:** Stefan 3D AI (@Stefan_3D_AI)
**Model:** UniMate (open-source)
**Source:** [https://x.com/Stefan_3D_AI/status/2104981826888675532](https://x.com/Stefan_3D_AI/status/2104981826888675532)

## Prompt

Generate motion from text prompts for rigged 3D characters. One model supports different skeletons. Edit motion while keeping joints unchanged. Export as FBX and GLB. MIT-licensed code with downloadable weights.

## Output

Open-source text-to-animation supporting multiple character rigs.
