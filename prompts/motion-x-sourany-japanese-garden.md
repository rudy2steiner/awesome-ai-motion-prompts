## Prompt

```
Create an interactive Japanese garden pond in a single HTML file using Opus 5.5. The pond should have koi fish swimming in realistic patterns, lily pads floating on the water surface, and a small stone lantern at the edge. When the user clicks or taps on the water, ripples should spread outward from the touch point, disturbing the fish and lily pads. The fish should react by swimming away from the ripple origin and then gradually returning to their natural patterns. Use CSS for the visual styling and JavaScript for the physics simulation. The scene should be peaceful and meditative, with a muted color palette of greens, blues, and earth tones.
```
