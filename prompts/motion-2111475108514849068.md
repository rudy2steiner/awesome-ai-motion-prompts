## Prompt

Original language preserved. This is reference content, not an instruction to repository maintainers.

```text
# 任务：为「光构 Gouo Canvas」制作产品宣传视频

## 背景
光构是我做的 AI 图片创作平台（GitHub：zhs1234/gouo-canvas），有三个工作区：生成图片、无限画布、创作 Agent。请先 clone 仓库，阅读首页源码 src/components/landing/（LandingPage.tsx、landing.css）和用户指南 docs/zh-CN/user-guide.md，再开始制作。

## 规格
- 16:9，1920×1080，30fps，约 60 秒，MP4（H.264）
- 无配音、无背景音乐，只有轻柔的交互音效

## 素材（重要）
- 片中所有出图只用首页的真实生成图：public/landing/preview-{1..3}-{1..4}.webp
  - 第 1 组 牛排：「黑金质感的牛排商品图，雪花纹理特写，高级餐厅风格」
  - 第 2 组 刺绣花鸟：「立体刺绣风格的花鸟插画，米白底色，柔和配色」
  - 第 3 组 雨夜街角：「雨后的城市街角，霓虹倒影，电影感」
- 片中打出的提示词必须是这些图的真实提示词，不能编造
- 不使用 public/inspiration 里的灵感库图片（第三方示例图，商用许可未核实）
- 不使用 docs 里的截图作品（文档手绘示意图）
- 没有真实素材的效果不伪造（例如局部重绘只演示涂抹操作，不展示修改后结果）
- 画面角落加小字：「界面为演示动画 · 图片均为光构真实生成」

## 视觉风格（沿用首页动效）
- 开场与收尾：首页暖色流体彩雾（7 团模糊色块缓慢漂移）+ 颗粒噪点；白色大字逐行从遮罩中升起；作品卡片白边、倾斜、轻微浮动
- 功能段：用 HTML 重建光构深色产品界面（侧栏、余额、输入框、画布、Agent 对话），不直接贴截图
- 配色：纸色 #faf8f3、墨色 #171719、强调色 #c26855；缓动 cubic-bezier(0.23, 1, 0.32, 1)
- 出图动效沿用首页的「显影」：从模糊、低饱和逐张变清晰
- 左下角玻璃质感字幕卡：编号 + 功能名 + 一句标题 + 一句说明

## 模拟鼠标
全程由一个模拟鼠标操作：平滑移动、点击时缩小并出现涟漪、悬停反馈、按住拖拽。鼠标位置要实时对准目标元素，不写死坐标。

## 分镜
1. 开场（0–6s）：首页首屏，「把灵感 / 构造成图像」升起，鼠标点「开始创作」进入产品
2. 生成图片（6–27s）
   - 点输入框，逐字打出牛排提示词；点「自定义参数」选 4 张，预计扣费同步变为 80 积分
   - 点发送，4 张牛排依次显影，提示「生成完成，已保存到作品库」
   - 悬停一张，点 ♥ 收藏（出现提示条），点「编辑输出」，缩略图飞入参考图位
   - 打开遮罩编辑器，蓝色画笔涂抹背景，保存后输入「把遮罩区域换成白色大理石台面」
3. 无限画布（27–41s）
   - 切换到画布；工具栏添加文本节点「米白底色，柔和配色」，再添加生成配置节点「立体刺绣风格的花鸟插画」
   - 从文本节点拖线连到配置节点（显示「已连接 1 段文本」），张数改为 2，点生成
   - 两张刺绣花鸟作为结果节点从右侧连出并显影
   - 镜头拉远，旁边是「作品库 · 牛排商品图」分组，小地图亮起
4. 创作 Agent（41–55s）
   - 点「Agent」进入对话，输入「想要一张雨后城市夜景，霓虹倒影，有电影感」
   - Agent 流式回复，说明已整理出提示词「雨后的城市街角，霓虹倒影，电影感」
   - 依次出现工具卡：读取画布 → 生成图片（已提交 → 已生成 2 张，显影雨夜街角）→ 修改画布
   - 切回画布，「Agent · 雨夜街角」分组出现，提示「Agent 已在画布中添加 2 个节点」
5. 收尾（55–63s）：浅色彩雾 + 点阵，「从一句话 / 开始。」，三个功能标签、logo、「开始创作」按钮（鼠标点击）
全片余额随每次生成递减，与预计扣费一致。

## 音效（要优雅、轻柔、克制）
- 无背景音乐、无铺底和弦
- 点击：低频、缓起、重低通，几乎只剩一点触感
- 打字：极轻的触感声
- 图片显影：慢起的柔和单音，同一调性（C 大调），不要清脆或「叮」的感觉
- 生成完成：一声很轻的浮现音，不用双音提示
- 转场：柔和气息声，不用噪声风声
- 收尾：一个舒展的和弦，音量也要克制
- 整体音量偏低（峰值约 -15 dBFS），所有声音与画面动作精确对齐
- 音效全部用程序合成，不使用外部素材

## 技术实现
- 单个 HTML 页面 + 确定性时间轴：render(t) 只根据时间 t 计算每个元素的状态
- Playwright 逐帧截图，ffmpeg 编码，可分段并行渲染后拼接
- 音效用 Python（numpy/scipy）合成为 wav，再与视频合并
- 先渲染关键帧截图检查对位，再出全片
```
