# Video 2 GLSL: Turning Reference Videos into Editable Shader Code

**Author:** gokaygokay (@gokayfem)
**Model:** Claude Opus 5.5 + shader-skills plugin
**Source:** [https://x.com/gokayfem/status/2112184819115336014](https://x.com/gokayfem/status/2112184819115336014)

## Prompt

Open-source tool (shader-skills) that generates REFERENCE.md from video input, then produces GLSL/WGSL shader code. Spec includes clip facts, shot timeline, object inventory, subject proportions, motion, camera framing, lighting and sampled palette. Repo: github.com/gokayfem/shader-skills.

## Output

Open-source pipeline converting video references to editable GLSL/WGSL shader code.
